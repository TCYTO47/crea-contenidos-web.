# CREA Contenidos · sitio web (maqueta)

- `index.html`: página única.
- `data/metrics.json`: cifras con plataforma, periodo y fuente.
- `data/clients.json`: muro de marcas (apagado hasta autorización).
- `docs/CREA_MAESTRO.md`: fuente única de verdad.
- `ESTRATEGIA.md`: estructura, decisiones y pendientes.

Para verlo en local: `python3 -m http.server` y abre http://localhost:8000
